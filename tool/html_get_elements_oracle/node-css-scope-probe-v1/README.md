# Node CSS scope observation

One getter script runs through the unchanged frozen `GetElementsOracleKt` classes and pinned JARs; no sources are recompiled. `manifest.json` binds the input, output, class/source hashes and command. Raw files are pinned in `pins.json`.

The returned-node control in `test/html_get_elements_test.dart` adapts Java `size()` to the existing JS `length` accessor across the product item boundary. External ancestor selectors return zero within each node scope. The additional `:nth-child` counts include matching descendants and retain the original sibling position.

This is a getter observation plus an equivalent producer control, not execution of the whole frozen BookList or an Android-device row.
